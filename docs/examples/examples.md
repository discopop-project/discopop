# Examples

The walk-throughs below use the program `example/example.cpp` of the repository: two loops over an array, an initialization loop (a do-all) and a summation loop (a reduction). Copy the folder before you start, e.g. `cp -r example /tmp/dp_example`.

- [Command line walk-through](walk_through.md): instrument, run, analyze and parallelize the example with the individual tools.
- [Project manager on the command line](project_manager_cli.md): the same workflow organized by `discopop_project_manager`, including measurements, a report and autotuning.
- [GUI walk-through](walk_through_gui.md): the complete workflow in the graphical user interface `discopop_gui`.
- [VS Code extension walk-through](walk_through_vscode.md): browse and apply the suggestions of an analysis inside VS Code.
