# DiscoPoP GUI
This package (`discopop-gui`) holds GUI components of DiscoPoP, for example graph visualizers based on matplotlib and networkx. It declares no console script.

The graphical user interface itself, started with `discopop_gui`, ships with `discopop-library` (`library/discopop_library/ProjectManager/gui`). `pip install discopop` installs both packages, as `discopop` depends on `discopop-gui` and `discopop-library`.

Documentation: [Graphical user interface](https://tuda-hpclab.github.io/discopop/tools/GUI/) and [Getting started](https://tuda-hpclab.github.io/discopop/getting_started/).
